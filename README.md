A 24.5-second, 9:16 Instagram Reel ad for **Ezy Pzy Convenience**
(153 Great Northern Rd, Sault Ste. Marie, ON P6B 4Y9) featuring four
Bucked Up Lightly Carbonated Protein flavours. Each drink gets its own scene.

## How it was made

No stock footage, templates or licensed audio were used. Everything is generated by code:

- **`src/extract_cans.py`** cuts each can out of its photo using two segmentation models (ISNet and U²-Net, through `rembg`) and cleans up the edges. The label pixels are never altered.
- **`src/fx.py`** is the effects engine:
  - A "2.5D" can renderer: the label is remapped onto a cylinder so the can appears to rotate a little. It also adds a moving specular highlight, coloured rim lights and a floor reflection.
  - A metaball liquid simulator with surface normals, so splashes and waves look glossy and 3D.
  - Refractive ice cubes, fractal-noise mist, procedural lightning, particles, bloom, film grain, chromatic aberration, motion blur and zoom blur.
- **`src/render.py`** holds the scene choreography and camera keyframes and renders the frames in parallel.
- **`src/audio.py`** synthesizes the whole soundtrack from scratch: an original electronic/hip-hop track plus every sound effect. Kick, 808, claps, supersaw hook, pads, arps, splash, fizz, can crack, ice clinks, zaps, thunder, whooshes, risers and impacts are all generated in code. It's mastered to about −10 LUFS with a −1 dBTP ceiling. **The audio is 100% original**, with no copyright claims.
- **`src/timeline.py`** is the single timing source shared by picture and sound, so they stay frame-locked.
- **`src/thumbnail.py`** builds the cover image.

## Rebuild

```bash
pip install -r requirements.txt
./build.sh                    # full pipeline (~5 min on 4 cores)
SKIP_CUTOUTS=1 ./build.sh     # reuse the cutouts in assets/cutouts
python3 src/render.py --test 3.5,8.0   # preview single frames into output/build/test/
```

## Notes and limitations

- **Store logo:** no logo was supplied, so the end card uses typography only (Inter Display). No logo was invented. To add the real logo, drop a transparent PNG in `assets/` and composite it in `end_card()` in `src/render.py`.
- **Product fidelity:** the cans are the supplied photos, never redrawn. The "orbit" is a gentle ±8° cylindrical rotation of the real label art. Real 3D turnarounds aren't possible from a single front photo.
- **Claims:** on-screen copy only repeats what is printed on every can ("25G PROTEIN", "LIGHTLY CARBONATED").
- Fonts: Inter / Inter Display (SIL Open Font License), included in `assets/fonts/`.
